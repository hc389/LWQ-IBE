# 统计适用性、可复现性和验证

## 1. 单位与重复

单位是一个明确的有限参数配置，不是实验受试者或随机重复。维数初筛45点，最终基线3点，每点6攻击；本文3个经典配置，每点6项历史攻击精确输入绑定复用。模数搜索对各固定配置确定性枚举，每个更小位长记录失败原因。基线不增加压缩。

没有以样本分布估计平均尺寸；字节计数是精确整数。因此均值±标准差、置信区间、p值、显著性与多重比较校正均不适用，不编造误差条。主要效应量是绝对字节变化和相对百分比，均在comparison.json及报告中列出。
